# Architecture Overview

Layer 1: Evidence Commitment
- Canonical JSON
- SHA-256 hashing
- Deterministic bytes

Layer 2: Release & Versioning
- Manifest structure
- Semantic versioning
- Ordered releases

Layer 3: Profiles (Future)
- Domain-specific extensions
- Must not break Layer 1 invariants

Out of Scope (v0.1.0):
- Anchoring infrastructure
- Registry backend
- Governance mechanisms
- Signature layer
